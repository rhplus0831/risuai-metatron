# Surveys

Read-only studies of other projects, written as input for plans. The fork surveys were
written on 2026-10-20 against metatron `44e18f2ae`: they list what each fork has that
metatron lacks, what metatron already covers, and what should not be ported. The memory
system reports followed on 2026-11-01, and the data-loss cross-check of the forks' fix commits on
2026-11-17 against metatron `003f367fc`, and the chat scroll survey on 2026-11-18 against `3b5d7ce6f`. None of them
changed code, except the chat scroll survey, whose fixes landed with it. The decisions the
surveys left to the owner are in [open decisions](../../backlog/open-decisions.md).
