# Problems noticed in the forks during the data-loss cross-check (2026-11-17)

While reading the forks' fix commits for the [data-loss cross-check](fork-data-loss-crosscheck.md), the stage 1 agents
noticed nine places where a fork's current code still looks able to lose data. They were not hunting for these, so
the list is not a review of the forks. It is kept here so the items can be reported to each fork's maintainers.

Every item was found by static reading at the fork's `HEAD` on 2026-11-17. None was reproduced. The "Session check"
column says how far this session looked: `read` means the cited lines were read and match the description, `not
read` means only the agent saw them. Before reporting an item, reproduce it in that fork.
